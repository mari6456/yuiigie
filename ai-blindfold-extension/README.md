# 講座用 目隠し拡張（ChatGPT / Meta AI・Muse）

講座や画面共有のときに、**サイドバーの履歴・ホームの提案・プロジェクト**をぼかす Chrome 拡張です。
**今動かしているチャットと入力欄はぼかしません。** ぼかした項目は**カーソルを合わせるとその1項目だけ**見えます。

ChatGPT 用と Muse 用は別々の拡張です。

| 拡張 | フォルダ | 対象サイト |
|---|---|---|
| ChatGPT目隠し（緑のアイコン） | `dist/chatgpt-blindfold` | chatgpt.com |
| Muse目隠し（青のアイコン） | `dist/muse-blindfold` | meta.ai |

## インストール方法

1. `dist/chatgpt-blindfold` と `dist/muse-blindfold` のフォルダをパソコンに置く（zip で受け取ったら展開する）
2. Chrome のアドレスバーに `chrome://extensions` と入力
3. 右上の「**デベロッパーモード**」をオンにする
4. 「**パッケージ化されていない拡張機能を読み込む**」→ フォルダを選ぶ（2つとも入れる場合は2回やる）
5. パズルのアイコンからピン留めしておくと便利です

## ぼかされる場所

- **サイドバー**：チャット履歴、プロジェクト一覧、アカウント名
- **新規チャットを開いた時**：入力欄以外（あいさつ・名前・おすすめ提案など）
- **プロジェクトを開いた時**：プロジェクト名、プロジェクト内のチャット一覧、上部のプロジェクト名表示
  （プロジェクト内でチャットをしている時も、上部のプロジェクト名はぼかしたままです）
- メッセージを送ると、そのチャットのやりとりは普通に見えます

## 使い方

- アイコンをクリックすると設定が開きます
  - **目隠し ON**：全体の ON / OFF
  - **サイドバー** / **ホーム・プロジェクト画面**：場所ごとの ON / OFF
  - **カーソルを合わせたら見える**：OFF にするとホバーしても見えません
  - **ぼかしの強さ**
- **ショートカット `Alt + Shift + B`** で ON / OFF（Mac は `Option + Shift + B`）
  ※ 2つとも入れると同じキーが重なるので、`chrome://extensions/shortcuts` で片方を変えてください
- ぼかした所も**クリックはそのまま使えます**（履歴を開くなど）

### ぼかしが足りない所を追加する

1. アイコン →「＋ ぼかす場所を手動で追加」
2. ぼかしたい場所をクリック（**マウスホイール↑で範囲を広げる** / ↓で戻す）
3. ぼかした場所をもう一度クリックすると解除
4. `Esc` で終了

追加した場所は保存され、次回からも自動でぼかされます。「リセット」で全部消せます。

## 注意

- ChatGPT や Meta AI の画面デザインが変わると、ぼかしが効かない場所が出ることがあります。
  その場合は「手動で追加」で対応できます。講座の前に一度、画面共有の見え方を確認してください。
- 画面を開いた直後の一瞬は、チラ見え防止のため画面全体がぼけます。

## 開発者向け

- `common/`：両方に共通のコード、`sites/chatgpt/`・`sites/muse/`：サイトごとの設定（`site.js`）、マニフェスト、アイコン
- `./build.sh` で `dist/` に2つの拡張フォルダと zip を作ります
